  • Lên kế hoạch cải tiến

  • Viết prompt mô tả feature

  • Iterate nhanh

Phase 4: Verification ✅

  • AI generate unit tests
  • AI review security
  • Integration test
  • Final deploy

✍️ Quy tắc Prompt Engineering

Rule 1: Context First 🎯

Luôn cung cấp ngữ cảnh đầy đủ: tech stack, cấu trúc hiện tại, mục tiêu cụ thể.

"Trong dự án Spring Boot 3 + Kafka
+ MongoDB, hãy tạo..."

Rule 2: One Feature at a Time 🧩

Prompt từng tính năng nhỏ thay vì prompt quá lớn một lần.

Rule 3: Specify Output Format 📄

Yêu cầu format cụ thể: Entity, Repository, Service, Controller, Config...

Rule 4: Iterative Refinement 🔁

Dùng kết quả AI làm base, tiếp tục prompt để cải thiện và tinh chỉnh.

⚙️ Enhanced: Saga Pattern (AI-generated)

Order Service – Distributed Transaction với Kafka

Luồng Saga:

1. startOrderSaga() → publish inventory-reserve
↓ (success)
2. publish payment-process
↓ (success)
3. Confirm order ✅
↓ (failure)
Compensate: Cancel order ❌
@Service
public class OrderSagaOrchestrator {

  @Autowired
  KafkaTemplate kafkaTemplate;

  public void startOrderSaga(
      CreateOrderRequest req) {
    kafkaTemplate.send(
      "inventory-reserve-topic",
      new InventoryReserveEvent(req));
  }

  @KafkaListener(
    topics="inventory-reserve-result")
  public void handleResult(
      InventoryResultEvent event) {
    if (event.isSuccess()) {
      kafkaTemplate.send("payment-topic",
        new PaymentEvent(event.getOrderId()));
    } else {
      orderRepo.updateStatus(
        event.getOrderId(), CANCELLED);
    }
  }
}
